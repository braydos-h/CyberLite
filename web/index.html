The 6–8 GB memory budget

At 0.853B parameters, the weights take about 1.6 GiB in 16-bit and about 0.4 GiB at 4-bit. Activations, optimizer state and the CUDA context decide whether a run fits.

Safety boundaries

Inference, autocomplete, evaluation and the server return text as data. No generated command is executed; Python is parsed with ast.parse; retrieved evidence is labelled untrusted.
