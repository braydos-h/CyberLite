# Processed data (not committed)

Generated by `scripts/prepare_dataset.py`. Each output directory contains:

- `train.jsonl`, `validation.jsonl`, `test.jsonl`
- `quarantine.jsonl` with rejected-record reasons
- `manifest.json` with dataset version, hashes, license counts, dedup and
  contamination statistics

The tiny smoke split is generated into `data/processed/smoke/` by:

```bash
python scripts/prepare_dataset.py --smoke
```

Processed corpora are intentionally excluded from version control. Reproduce
them from the manifest and source versions instead of committing bulk data.
